### Начать играть

1. Открой [последний выпуск](https://github.com/eweew1/fora-releases/releases/latest) и скачай установщик `.exe`.
2. Установи FORA и войди в аккаунт.
3. Выбери игру и скачай доступный трейнер.
4. Запусти игру, затем трейнер из FORA.

Для установки приложения нужен только файл `.exe`. Трейнеры скачиваются отдельно — весь каталог загружать не нужно.

### Что есть в FORA

- Библиотека игр, избранное и установленные трейнеры.
- Загрузка, обновление и удаление трейнеров прямо из приложения.
- Настройки автозапуска и сворачивания в трей.
- Раздел с официальными ссылками на компоненты и драйверы.

Для работы трейнера нужны аккаунт, интернет и открытая FORA. Игры добавляем постепенно; доступность каждой видна в каталоге.

### Обновления

FORA проверяет новые версии автоматически. Когда обновление загрузится, приложение предложит перезапуск.

Кнопка **«Скачать FORA»** всегда ведёт к актуальному выпуску.

### Если что-то не работает

Загляни в **«Драйверы и компоненты»** внутри FORA. Если проблема осталась, [сообщи о ней](https://github.com/eweew1/fora-releases/issues/new): напиши версию FORA, название игры и что произошло. В настройках можно скопировать сведения для поддержки.
